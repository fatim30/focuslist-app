# Vector Parkour 2D

> Game parkour 2D berbasis vector dengan kontrol lompat, double jump, dan sistem skor.

🌐 **Live Demo:** [https://fatim30.github.io/focuslist-app/](https://fatim30.github.io/focuslist-app/)

## Fitur Utama
- 🏃 Karakter vektor bergaya polygon
- 🏢 Rintangan bangunan/rumah/box dengan desain vector berbeda
- 🦘 Double Jump - maksimal 2 kali lompat di udara
- 📊 Sistem skor dan high score tersimpan di localStorage
- 🎮 Kontrol: Space/↑ untuk lompat, ↓ untuk jatuh cepat, sentuh layar
- 🌓 Tema gelap/terang
- 📱 Responsif untuk mobile, tablet, dan desktop
- Single-file Vanilla HTML5, CSS3, Canvas, & Modern ES6 JavaScript (No Build Tools Required).

## Cara Menjalankan Secara Lokal
Cukup buka file `index.html` di browser favorit Anda atau gunakan server lokal:
```bash
# Python simple server
python3 -m http.server 8000
```
